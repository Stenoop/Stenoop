# Sténoop

**Open source, local-first software for agentic workflows.**

Sténoop builds tools that make AI-assisted work easier to structure, inspect and reuse.

The main project is **SwarmOp**: a conversational and visual studio that turns a business intent into an executable, observable and exportable agentic graph.

SwarmOp starts from a real-world request — a proposal response, a technical brief, a document review, an analysis workflow — and helps structure it into agents, roles, inputs, outputs, artifacts, validation steps and execution traces.

The goal is not to hide work behind a chatbot interface.

The goal is to make agentic workflows visible: what is being done, by which agent, from which inputs, with which intermediate artifacts, and under which validation rules.

Sténoop focuses on software infrastructure for teams that need more than a prompt and less friction than a custom orchestration stack.

Current work focuses on SwarmOp Studio, local execution, runtime observability, and exportable work packages.
